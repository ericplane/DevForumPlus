DataStore :GetAsync() throttling on high player counts

Request budgets are per-server, not per-key. If you are seeing DataStoreService throttling at high player counts, the usual cause is one call per player per heartbeat rather than a batched write.

The pattern we recommend:

local function safeGetAsync(store, key)
	local attempts = 0
	while attempts < 3 do
		local ok, result = pcall(store.GetAsync, store, key)
		if ok then
			return result
		end
		attempts += 1
		task.wait(2 ^ attempts)  -- exponential backoff
	end
	error("GetAsync failed after 3 attempts")
end
Note that UpdateAsync counts against both the read and write budget.
